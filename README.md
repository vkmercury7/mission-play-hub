# Kit Missão Criativa

Crie uma página de vendas PREMIUM, altamente persuasiva e otimizada para conversão para um produto digital infantil chamado:

KIT ANTI-TÉDIO

Subtítulo:
Brincadeiras e desafios para transformar o “TÔ ENTEDIADO!” em diversão — sem depender de celular, tablet ou TV.

IMPORTANTE:
Esta NÃO deve parecer uma landing page genérica de ebook ou um template de Canva.
Quero uma página de vendas com aparência de produto digital profissional, moderno, confiável e extremamente bem produzido.

O público comprador são PAIS E RESPONSÁVEIS por crianças.
A criança é quem utiliza o produto, mas toda a comunicação de venda deve conversar principalmente com o pai/mãe.

O objetivo principal da página é:
FAZER O RESPONSÁVEL QUERER COMPRAR O KIT IMEDIATAMENTE.

A página deve ser emocional, visual, dinâmica e extremamente clara.

==================================================
IDENTIDADE VISUAL

Crie uma identidade visual própria para o KIT ANTI-TÉDIO.

Paleta principal:

Azul profundo / azul royal para confiança e contraste

Amarelo quente para energia e diversão

Coral para chamadas e elementos de destaque

Branco/off-white para áreas de leitura

Roxo em pequenos detalhes

Evite:

visual infantil exagerado;

excesso de rosa;

aparência escolar genérica;

excesso de elementos fofinhos;

aparência de site feito por IA;

gradientes exagerados;

excesso de emojis;

visual amador.

Quero um design que pareça uma marca real de produto digital infantil.

Use:

cards modernos;

bordas arredondadas;

sombras suaves;

ilustrações modernas;

pequenos elementos gráficos relacionados a brincadeiras;

tipografia grande e extremamente legível;

excelente espaçamento;

hierarquia visual forte.

A página precisa funcionar perfeitamente no celular, pois grande parte do tráfego virá de anúncios do Meta.

==================================================
IMAGENS

Use imagens/ilustrações profissionais que transmitam:

crianças brincando longe de telas;

crianças desenhando;

crianças fazendo desafios;

crianças brincando com os pais;

crianças realizando atividades criativas;

momentos de diversão em casa.

IMPORTANTE:
As imagens devem parecer fotografias/editoriais ou ilustrações premium de uma marca infantil real.

NÃO use imagens com aparência artificial, genérica ou claramente geradas por IA.

Se necessário, utilize imagens apropriadas de bancos de imagens ou crie placeholders elegantes para que eu possa substituir posteriormente.

Crie mockups profissionais do próprio KIT ANTI-TÉDIO:

capa principal;

páginas internas;

cartões de desafios;

atividades;

calendário;

sistema de missões;

materiais imprimíveis.

O produto deve parecer GRANDE e VALIOSO.

COPYWRITING

A comunicação deve seguir esta lógica:

DOR:
“Meu filho está entediado.”

PROBLEMA:
“Ele pede celular, tablet ou TV.”

CULPA/FRUSTRAÇÃO:
“Eu não tenho ideia do que fazer toda hora.”

SOLUÇÃO:
“Tenho uma coleção de missões prontas.”

TRANSFORMAÇÃO:
“Agora tenho uma alternativa para aqueles momentos.”

AÇÃO:
“Quero meu Kit.”

Utilizar frases curtas, fortes e fáceis de escanear.

Não transformar a página em um texto gigante.

Criar contraste entre títulos grandes e blocos curtos.
